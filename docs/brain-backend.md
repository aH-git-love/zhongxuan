# 大脑规则引擎与后端（rules-v3）

## 已实现范围

这是73条流程规则驱动的可解释检索与反馈重排引擎，不是新训练的神经网络或外部大语言模型。另提供独立的本地知识索引：78张塔罗牌、7个牌阵、24种推演方式、284条术数条目、32条典籍目录/摘句及22个案例；命中展示来源定位，正位与逆位分别读取牌库字段。结果展示命中词、证据分、有限反馈加权、处理链、方法库/术数库关联。检索强度是证据等级，不是预测正确率；跨场景接近时提示确认问题，零命中时请求补充事实。

浏览器与Node后端复用 js/brain.js。后端在线且登录时使用当前账号的持久化状态；匿名请求使用公共基线，不落盘。没有Node后端的静态站点继续运行本地规则，并显示实际推理来源。后端请求失败时切回本地推理，前端明确标注，反馈不冒充已保存到服务端。

## 启动

需要现代Node.js；当前测试环境Node 24。无npm运行依赖。

```bash
node server.js
```

默认端口8765。环境变量PORT可调整端口，ZX_DATA_DIR可指定持久数据目录。所有用户、会话及大脑状态使用该数据目录。生产运行将ZX_DATA_DIR绑定到持久磁盘；当前JSON方案面向单个Node进程，尚未实现跨进程数据库事务和多副本协调。

浏览器打开该Node服务的根网址，账号模块会检测 api/ping，自动使用 api/brain/*。不要把服务器监听端口当作已部署的公网服务。

## 接口

| 路径 | 方法 | 作用 |
| --- | --- | --- |
| /api/brain/status | GET | 公共能力、引擎版本、规则数 |
| /api/brain/analyze | POST | 分析问题；登录后应用独立状态 |
| /api/brain/state | GET | 当前登录身份的权重和统计 |
| /api/brain/feedback | POST | 反馈当前身份分析实际匹配的规则 |
| /api/brain/reset | POST | 仅重置当前身份状态和待反馈记录 |

分析JSON：`{"text":"不知道出生时辰怎么排盘","scene":"全部"}`。text去除首尾空白后1–4000字符；scene须为既有场景或全部。请求体上限16KiB。登录沿用现有 /api/login；后续携带 `Authorization: Bearer <token>`。

反馈JSON：`{"inferenceId":"<分析返回的UUID>","ruleId":"D02","good":true}`。good必须是布尔值。反馈必须对应当前账号分析的命中规则；重复同票返回duplicate:true，不再学习；同一规则反向票返回409。每次分析的每个命中规则计票一次，而非全局只计一次。

分析限流每身份或匿名IP每分钟30次；反馈每身份每分钟60次。限流仅在单个Node进程生效。

## 状态与数据

状态保存于 `ZX_DATA_DIR/brain-users/<身份摘要>.json`（默认data/brain-users）。正式账号按服务端认可的账号名隔离；同名游客按会话token隔离。临时文件写入后原子重命名。损坏文件返回500并保留原文件，避免静默覆盖。记录上限100次，7天过期；只保存分析ID、时间、匹配规则与反馈，不存用户原始问题。

反馈权重1–30，实际排序影响最多±1.5分；反馈不产生无关键词依据的候选规则。各账号不改动公共基线。API响应为no-store，SW v14直接放行API，不把账号状态缓存到静态离线资源中。

## 运行位置与发布

官方网页仍为 https://ah-git-love.github.io/zhongxuan/ 。当前GitHub Pages发布形态没有运行本项目Node API；该网址使用升级后的本地规则引擎。此次已完成Node后端代码和本机端到端测试，尚未建立公网Node实例，也未连接外部模型服务。

要启用公网后端，在具备Node运行能力与持久磁盘的服务器部署同一目录，运行server.js，由同一HTTPS来源同时提供网页和api路径。后台托管的主机、域名、进程管理与反向代理属于服务器配置；现有仓库没有相应的已部署服务凭据或实例记录。继续保留唯一网页入口和无需重装更新的流程。
