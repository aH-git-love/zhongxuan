# 大脑知识源与追溯清单

## 当前索引范围

`BRAIN_KNOWLEDGE.stats()` 当前索引四个运行时源：

- `js/tarot.js`：78 张牌、7 个牌阵，牌义来自 `TAROT.ALL` 与 `TAROT.SPREADS`。
- `js/methods.js`：24 种推演方式，定位格式为 `METHODS.get('Mxx')`。
- `js/yishu.js`：252 条术数条目、32 条典籍目录，定位格式为 `YISHU.<GROUP>[index]`。
- `js/cases.js`：22 个案例，定位格式为 `CASES_LIB.byId('ID')`。

当前总索引量为 **428**：78 + 7 + 24 + 252 + 32 + 13 条经典摘录 + 22。

## 可复核原始材料

项目内置的原始材料分为两层：

1. **运行时结构化资料**：上述四个 JavaScript 模块。检索结果直接带文件和 API 定位，不复制一份平行牌库或术数库。
2. **研究与案例材料**：`tools/books/` 下的文本资料，包括《卜筮正宗》《增删卜易》网页转存文本及案例原文。它们用于整理案例和规则，不声称已经完整收录整部典籍。

塔罗图像另有独立来源清单：`assets/tarot/rws/sources.json`，来源说明见 `docs/tarot-art-sources.md`。图像来源和牌义字段来源分开记录。

## 检索规则

- 塔罗牌必须先解析到唯一 ID，再读取正位 `TAROT.byId('ID').up` 或逆位 `TAROT.byId('ID').rev`。
- 牌阵使用 `TAROT.SPREADS.find(s=>s.id==='ID')`，牌位不从自然语言猜测。
- 方法使用 `METHODS.get('Mxx')`，案例使用 `CASES_LIB.byId('ID')`。
- 术数条目带 `YISHU.<GROUP>[index]` 定位；典籍目录是索引和摘录，不代表整部原书已进入运行时知识库。
- 检索命中是资料定位，不等于事实预测；跨体系同名词必须经过场景过滤和歧义规则。
