## 二、七个核心模块

### 1. 排盘（生辰八字）

输入公历生日 + 时刻 + 性别，输出：

- **四柱**：年柱、月柱、日柱、时柱（干支大字）
- **十神**：每柱天干对日主的关系（比肩/劫财/食神/伤官/偏财/正财/七杀/正官/偏印/正印）
- **藏干与藏干十神**：地支本气/中气/余气
- **纳音、五行、十二长生**
- **五行分布条形图**：含藏干加权（本气 0.6 / 中气 0.25 / 余气 0.15）
- **日主旺衰**：同党（比劫+印）占比 → 偏强 / 中和 / 偏弱
- **喜用神（简化）**：偏弱喜印比、偏强喜克泄耗
- **神煞**：天乙贵人、文昌、羊刃、桃花、驿马、华盖、将星、孤辰、寡宿
- **大运**：阳男阴女顺排、阴男阳女逆排，按"到节气天数 ÷ 3"折算出起运年月，列 10 步
- **近十年流年**：每年干支 + 十神 + 与本命四支的冲/合/害/半三合
- **三得法定旺衰**（滴天髓）：得令 / 得地 / 得势 → 中和 / 偏强 / 偏弱
- **格局**（子平真诠口径）：月令取格（八正格 + 建禄 / 羊刃 + 不透本气），含成格之相 / 破格之因
- **调候用神**（穷通宝鉴简表）：按 10 日干 × 12 节气月查表
- **命宫 / 胎元**（果老星宗口径）：命宫支 =（月支 − 时支）mod 12，天干按五虎遁；胎元 = 月干进一、月支进三
- **旬空（空亡）**：按日柱所在旬，标注四支落空情况
- **小运**（渊海子平）：起运前逐年，从时柱顺/逆推
- **原局干支关系**：六冲、六合、六害、六破、三刑、半三合、半三会、暗合、相夹全标注（带宫位）

排盘可选开关：
- **真太阳时**：经度差（每度 4 分钟）+ 均时差（±16 分钟）修正
- **23:00 后算次日**（子时换日，默认开启）
- 出生地经度（默认 116.4，即东经 120 口径下的北京）

### 2. 择日（良辰吉日）

12 类事项：嫁娶、开市、出行、入宅、动土、安葬、上任、求医、签约、祭祀、移徙、求财。

- 输入事项 + 起始日期 + 天数（最多 120）+ 主事人生肖 → 输出 **Top 10 吉日排行**
- 每日展示：日柱、建除十二神、黄道/黑道、冲煞、宜、忌、评分依据；**12 时辰吉凶默认折叠**，点「展开 12 时辰吉凶」查看，Top 10 更清爽
- 评分 = 建除事项匹配 ×10 + 黄道 +5 / 黑道 −5 + 避冲（−40）+ 吉时数量 + 硬凶日扣分（月破 −20）
- **单日黄历**：任意日期查完整黄历（建除释义、彭祖百忌、节气、神煞、十二时辰值神）
- **整月吉凶日历**：按月铺开 7 列日历，每天色标（金=大吉 / 绿=可用 / 灰=常日 / 红=凶日）显示日柱、建除、黄黑道与宜忌摘要；可选主事人生肖，冲日红框标"冲主"并从大吉日中剔除；底部汇总本月大吉日、凶日与冲主日；点任意一天直接展开当日完整黄历

### 3. 推演（流年大运 · 多流派并列）

- 选命例（排盘页可"保存命例"，存本地）+ 填年份（逗号分隔）→ 逐年输出
- **两种模式**：
  - **简明版**：流年干支、该年所属大运（十神）、流年支与四支的冲/合/害/半三合逐条列出、流年天干十神与主事含义
  - **多流派并列（7 派互证）**——每个流年输出七张卡片：
    1. **扶抑用神法**（滴天髓 / 子平真诠）：流年干支是帮扶用神还是助忌
    2. **调候用神法**（穷通宝鉴）：流年五行是否合本命调候之药
    3. **关系引动法**（三命通会）：刑冲合害破会夹拱全标注（带宫位），合多还是冲多
    4. **宫位六亲法**（千里命稿）：哪个宫位被冲/被合 → 对应六亲与年龄段议题
    5. **盲派串宫压运**：太岁压十二宫（命宫起逆布）→ 该年主题
    6. **病药应期法**（神峰通考）：药到 / 半药 / 守成 + 伏吟检测 → 应期强度
    7. **神煞流年法**（三命通会）：桃花 / 驿马 / 华盖 / 将星入命 + 冲太岁
- **综合分**：各派吉 +1 / 凶 −1 累加 → ≥3 强吉、1~3 偏吉、±1 平、≤−3 强凶
- 用法：先看综合分定基调，再看哪派给强信号，最后落宫位/十神定具体领域

> 本工具只做干支机械推演，不做人身断言；结论请结合实际。

### 5. 节气（精查）

任意年份 24 节气，精确到分钟（北京时间），并标注哪些是"节"（月柱分界：立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒），哪些是"中气"。

### 6. 大脑（决策推理引擎）—— 你要的"后台思考"

输入一段问题描述，引擎依次输出：

```
读取问题 → 匹配规则（关键词命中 + 权重）→ 问题定性 → 冲突检查 → 执行方案（分步）→ 注意点 → 推荐推演方式（方法库联动）→ 并行参考
```

**方法库联动（投喂大脑）**：方法论 10 条规则多数挂推演方式引用（M01~M24）；命中规则后，大脑自动推荐对应的推演方式卡片（方法 ID + 原理 + 何时用），推理链多一步"推荐推演方式"。例如问"用神怎么取"→ 命中 G01 → 自动推荐 M02 调候用神法 / M01 扶抑用神法 / M04 通关法 / M05 病药法。

## 三、排盘口径（重要，避免"算出来不一样"）

| 项目 | 口径 |
| --- | --- |
| 年柱分界 | **立春**（不是正月初一） |
| 月柱分界 | **十二节**（立春、惊蛰、清明…小寒），不是农历月 |
| 日柱 | 儒略日数推算：`(JDN + 49) mod 60`，对照 2000-01-01 戊午日校验 |
| 换日 | 默认 23:00 起算次日（可在排盘页关闭，改成 00:00 换日） |
| 时柱天干 | 五鼠遁：`(日干 mod 5) × 2 + 时支` |
| 节气/朔 | 定气定朔天文历（Meeus 太阳视黄经 + 月球相位算法），北京时间 |
| 农历 | 按"冬至所在月为十一月"+"无中气置闰"规则算，支持 1901-2100 任意日期换算 |

与别的 App 结果不同时，按顺序核对这四点：①年柱是否以立春为界 ②月柱是否以节气为界 ③日柱是否 23 点换日 ④是否做了真太阳时修正。99% 的差异出在这里（"大脑 → D03"规则里也写了这套排查法）。

## 八、是否需要部署到服务器？

**不需要。** 本应用是**纯静态页面**：无后端、无数据库、无网络请求（不打接口、不加载 CDN），双击 `E:\中玄\index.html` 即可在浏览器中直接使用（`file://` 协议完全兼容），数据全部保存在浏览器本地（localStorage）。离线、内网、无服务器环境均可运行。

如果只是想**多设备访问**（如手机/平板看），再考虑起个静态服务即可，三选一：

```bash
# 方式一：Python 自带（Windows/Mac/Linux 都有）
cd E:\中玄
python -m http.server 8080
# 手机连同一 Wi-Fi，访问 http://电脑IP:8080

# 方式二：Node
npx serve E:\中玄

# 方式三：长期使用挂到 IIS / Nginx
# 把 E:\中玄 整个目录设为站点根目录即可（纯静态托管，无特殊配置）
```

注意：起服务访问（`http://`）后，localStorage 的数据与 `file://` 打开时的数据**不互通**（浏览器按来源隔离），训练记录、大脑权重会各自独立。

| 使用方式 | 适合场景 | 是否要服务器 |
| --- | --- | --- |
| 双击 `index.html`（file://） | 单机自用 | 否 |
| `python -m http.server` | 手机/局域网临时访问 | 可选（一条命令） |
| IIS / Nginx 静态目录 | 长期多设备访问 | 可选 |

结论：**单机使用零部署，直接双击；要局域网/手机访问才需要起服务，且只是一条静态命令，不需要任何后端。**
